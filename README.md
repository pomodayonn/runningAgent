# RunRebuild v0.1.0

元短距離選手の持久力再構築を支援する、個人向けランニングWebアプリです。

## Macでの起動

1. Node.js 20.19+ または 22.12+ をインストール（Node.js公式サイト等）。
2. ターミナルでこのフォルダへ移動（`cd ` と入力後、フォルダをドラッグ＆ドロップしてEnterでも可）。
3. `npm install`
4. `npm run dev`
5. 表示されたURL（通常 `http://localhost:5173`）をMacのブラウザで開く。

## iPhone/Androidで確認

Macとスマホを同じWi-Fiに接続し、ターミナルに表示される Network URL をスマホで開きます。LAN上のHTTP接続では一部ブラウザ機能が制限される場合があります。実際の公開時はHTTPSを使用してください。開発サーバーはLANからアクセス可能になるため、信頼できるネットワークだけで使用してください。

## テスト・ビルド

```sh
npm test
npm run build
npm run preview
```

## 実装済み

- 8週間のランニングメニュー、週の手動切替
- ジョグ・歩行・準備運動・整理運動タイマー
- 一時停止、再開、途中終了、区間切替時の音・振動（対応端末のみ）
- IndexedDB（Dexie）での運動履歴保存、体感強度・脚の張り・メモ
- モバイル向けUI

## 注意点

- ブラウザがバックグラウンド・画面ロック状態になると、音・振動が動作しない場合があります。復帰後の表示は実経過時間に合わせます。
- 画面を閉じたりリロードすると、進行中の未保存セッションは失われます。
- 履歴はこのブラウザのローカル保存領域にあります。ブラウザデータ削除・プライベートブラウズ等で消えることがあります。v0.2以降にバックアップ機能を検討します。
- GPS、地図、AI、筋トレ、PWAオフライン対応は未実装です。
- 痛みや強い不調があるときは無理に運動を続けないでください。
